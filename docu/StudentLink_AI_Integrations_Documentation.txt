================================================================================

📱 OPENROUTER AI INTEGRATION
-----------------------------
Purpose: AI Writing Assistant for concern submission and text improvement

🔧 Configuration:
- API Key: OpenRouter.ai integration
- Base URL: https://openrouter.ai/api/v1
- Authentication: Bearer token with custom headers

🤖 AI Models Available:
1. Default Model: deepseek/deepseek-r1:free
   - Advanced reasoning capabilities
   - Excellent for writing assistance
   - High-quality responses with context understanding

2. Fast Model: grok-beta:free
   - Faster response times
   - Good for quick suggestions
   - Optimized for speed

3. Creative Model: meta-llama/llama-3.1-8b-instruct:free
   - Better for creative writing
   - More varied responses
   - Enhanced creativity

⚙️ Technical Settings:
- Max Tokens: 300
- Temperature: 0.7
- Top P: 0.9
- Timeout: 30 seconds
- Caching: Enabled
- Fallback: Template-based suggestions

✨ Features:
- Contextual AI-generated responses
- Copy functionality for suggestions
- Professional tone maintenance
- Inappropriate language filtering
- Context-aware suggestions based on concern type

🔄 Fallback System:
If API unavailable, system provides:
- Intelligent template-based suggestions
- Contextual responses based on concern type
- Professional tone and structure
- Clean language processing

4. N8N WORKFLOW AUTOMATION
================================================================================

🔄 AUTOMATED AI WORKFLOWS
--------------------------
Purpose: AI-powered automation for concern processing and management

🔧 N8N Configuration:
- Webhook URL: https://studentlinkbcp.app.n8n.cloud/webhook-test
- API Key: Environment variable
- Enabled: Configurable per workflow

📋 WORKFLOW 1: CONCERN CLASSIFICATION
-------------------------------------
Purpose: Automatic concern urgency classification and prioritization

🤖 AI Classification Logic:
- Enhanced keyword-based classifier
- Confidence scoring (0.6-0.9)
- Automatic priority updates
- Department suggestion

🎯 Classification Rules:
1. CRITICAL (Confidence: 0.9)
   Keywords: urgent, emergency, critical, asap, immediately, broken, 
   down, not working, error, crash, hack, security, breach

2. HIGH (Confidence: 0.8)
   Keywords: important, deadline, due, priority, issue, problem, 
   help, support, grade, exam, assignment

3. MEDIUM (Confidence: 0.7)
   Keywords: question, inquiry, information, request, general, 
   clarification

4. LOW (Confidence: 0.6)
   Keywords: thanks, thank you, appreciation, feedback, suggestion

🏢 Department Classification:
- Academic: grade, exam, assignment, course
- Finance: payment, fee, tuition, financial
- Housing: dorm, housing, room, accommodation
- Library: library, book, research, study
- IT: tech, computer, system, login, password

⚙️ Auto-Update Logic:
- Updates priority when confidence ≥ 0.7
- Sends notifications for high/urgent priorities
- Logs classification for audit trail

📋 WORKFLOW 2: AUTO-REPLY FAQ
-----------------------------
Purpose: Automatic responses to frequently asked questions

🎯 Features:
- FAQ matching with 80% confidence threshold
- Automatic reply generation
- Context-aware responses
- Reduces manual response workload

📋 WORKFLOW 3: ASSIGNMENT REMINDER
----------------------------------
Purpose: Automated reminder system for concern assignments

⏰ Reminder Intervals:
- Deadline Approaching: 24 hours before deadline
- Overdue: Immediately after deadline
- Escalation: 72 hours after deadline

🔄 Trigger Conditions:
- New concern assignment
- Status changes
- Deadline approaching
- Overdue concerns
